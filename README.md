# My Personal Pyramid

A personal strategy dashboard built for BYU STRAT 392 (Personal Pyramid Assignment).

It applies the Company Pyramid from class to my own life:

1. **Values & priorities** (the base)
2. **Resources & capabilities**
3. **Organization** (how my week is set up)
4. **Activities** (what actually happens)

Health sits underneath as the foundation.

## What's on the site

- **Overview:** clickable pyramid, alignment score, a 168-hour week chart, lifelines (priority vs. time), and misalignments
- **A tab for each value:** Love, Freedom, Growth, Faith, Character, and Health, each with resources, organization, activities, and a weekly tracker
- **Roadmap:** Part 2 checkpoints, what to build, acquire, and cut, and risks
- **Reflection:** insights, course connections, sources, and AI use disclosure

## Weekly tracker

Tracker entries save in your browser (localStorage), so they stay on the device you log them on.

## Updating

Edit `index.html` and push to `main`. GitHub Pages redeploys automatically.
